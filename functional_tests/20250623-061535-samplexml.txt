- **Test Case 1: Verify dropdown contains the new "claude-3-7-sonnet" model**
  - **Input:** Navigate to the relevant section of the Google Vertex AI interface where the Anthropic model dropdown is displayed.  
  - **Expected Output:** The dropdown should include "claude-3-7-sonnet" as an available selection.  
  - **Edge Case:** Validate the behavior when the dropdown contains many items (e.g., 50+ models). The new model should still be visible and selectable.

- **Test Case 2: Validate selection of "claude-3-7-sonnet" in the dropdown**
  - **Input:** Select "claude-3-7-sonnet" from the dropdown and confirm the selection.  
  - **Expected Output:** The system should correctly process the selection and display confirmation without errors.  

- **Test Case 3: Ensure proper model validation occurs**
  - **Input:** Select "claude-3-7-sonnet" as the model and initiate a request via the API after form submission.  
  - **Expected Output:** The model should successfully pass all internal validations.  

- **Test Case 4: API response with 200 OK for valid requests**
  - **Input:** Send a valid request using "claude-3-7-sonnet" as the selected model.  
  - **Expected Output:** API responds with a 200 OK status and a valid JSON response confirming model execution.  

- **Test Case 5: API response with 429 Too Many Requests error**
  - **Input:** Simulate a high number of API requests to trigger rate-limiting (e.g., send more than 20 requests per minute).  
  - **Expected Output:** API responds with a 429 "Too Many Requests" error containing the following details:
    ```json
    {
        "error": {
            "code": 429,
            "message": "Resource exhausted. Please try again later. Please refer to https://cloud.google.com/vertex-ai/generative-ai/docs/error-code-429 for more details.",
            "status": "RESOURCE_EXHAUSTED"
        }
    }
    ```

- **Test Case 6: Validate retry mechanism after 429 error**
  - **Input:** After receiving a 429 error, retry the API request after the cooldown period.  
  - **Expected Output:** Following the retry, the API should return a 200 OK response if the retry happens after the cooldown period.  

- **Test Case 7: Handle invalid input for the model API**
  - **Input:** Use "invalid-model-name" instead of "claude-3-7-sonnet" for the API request.  
  - **Expected Output:** Error response with the appropriate error code (e.g., 400 Bad Request) and a descriptive error message.
